# Parkinson's Disease Daily Research Digest

🧠 巴金森病（Parkinson's Disease）每日研究文獻自動摘要系統

- 每日自動從 PubMed 抓取最新巴金森病相關文獻
- 使用 AI（GLM-5-Turbo）進行分析、分類、總結
- 生成美觀的 HTML 報告並部署至 GitHub Pages

## Features

- 自動排除過去 7 天已總結的文獻（增量更新）
- 覆蓋核心期刊：Movement Disorders、Neurology、Brain、JAMA Neurology 等
- 覆蓋多領域：生物標記、治療、遺傳學、神經影像、非運動症狀、復健、營養、精神醫學、流行病學、照護者/生活品質
- AI 精選文獻（Top Picks）含 PICO 分析
- 暖奶油色/銅色視覺設計

## Schedule

- 每天台北時間 20:50 (UTC 12:50) 自動執行
